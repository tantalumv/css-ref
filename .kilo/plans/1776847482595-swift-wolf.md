# Plan: Expand Inline Critical CSS

## Problem
- Page flashes with unstyled/minimal layout before full CSS loads
- Current inline CSS (~1KB) only has basic shell - no grid/card styles
- Grid renders empty until JS loads, then renders cards after CSS finishes loading

## Goal
- Eliminate visual flash while maintaining Lighthouse performance score
- Keep total inline CSS under 14KB (compressed) to fit in first TCP roundtrip

## Current State
- Inline CSS: ~1KB (lines 32-45 in index.html)
- Bundle CSS: 86KB (external, loads async)
- Uses CSS variables: `--space-*`, `--shadow-*`, `--card`, `--primary`, etc.

## Approach
Expand existing `<style>` block to include critical above-the-fold styles.

---
